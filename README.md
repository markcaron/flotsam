## 🛟 Flotsam

A sundry collection of washed-up Web Components built with Lit 3 and TypeScript. Some may be more useful than others.

### How to get started

1. Clone the repo
2. `npm ci`
3. `npx cem serve` to run the dev server

The dev server is provided by [`@pwrs/cem`](https://github.com/bennypowers/cem), installed as a dev dependency.

### Project structure

```
elements/                          # Web components
  flotsam-scroll-progress/         # Scroll-aware reading progress gauge
```
